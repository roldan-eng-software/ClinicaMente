# ClínicaMente

MicroSaaS para gestão de clínicas de psicologia.

## Funcionalidades

- Gestão de pacientes
- Agenda e agendamento de consultas
- Prontuário eletrônico
- Dashboard e relatórios

## Tech Stack

- **Frontend**: Next.js
- **Backend**: Supabase
- **Hospedagem**: Vercel
- **Versionamento**: GitHub

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```
